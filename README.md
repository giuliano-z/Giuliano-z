> I built a system nobody used. Then I understood why — and that taught me more than any tutorial.

Since July 2025 I develop and operate a Django ERP for my family's health food store in Almafuerte, Córdoba. It handles inventory with FIFO batch tracking, wholesale purchasing, recipe costing, analytics and reporting. In production and daily use since December 2025.

The system worked from day one. It just wasn't being used — recording a sale took too long, so sales never got logged. More business logic wouldn't have fixed that. I built a barcode-scanner POS instead, and that's when it started running for real.

A correct system nobody uses is a system that failed.

What operating it taught me weighs as much as building it: 500+ automated tests, zero-downtime CI/CD, backups with tested restores, a postmortem for every incident and an inventoried tech debt. In October 2026 I handled a security incident at the hosting provider (environment variables exposed): backup, access audit and full credential rotation, with no service interruption. The code is private (real business data); 393 versions shipped in 16 months.
